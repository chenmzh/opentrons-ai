# OT-2 音域与节奏实测（2026-09-14）

两轮物理测试均成功，合计 311 次直接移动。结论适用于这台 OT-2 的 **X 轴、10 cm 区间、当前 Python API 分段运动方式和当前麦克风位置**；不是整个 OT-2 平台的绝对音乐性能上限。

- 按现有速度—音高映射，测试音符中有重复谐波证据的范围覆盖 **C1–A6（32.7–1760 Hz，5 个八度加 9 个半音）**。这是离散测试点的覆盖范围，没有逐半音验证。低音主要靠谐波推断，不能等同于听感清晰的纯音范围。
- 高音端 **A6 四次均检测到短暂稳定频段**；B6 和 400 mm/s 对应的约 1993.5 Hz 没有稳定复现。A6 合格频谱窗口中心只连续覆盖约 80–110 ms，长音不能照搬这个上限。
- 实用节奏开始受损的区域约为 **4–5 音/秒**。更稳妥的测试点为约 2.9 音/秒；最快测试整段吞吐为 **8.76 音/秒**，但只有 5/16 个音的频谱特征与参考对应。

## 官方边界与执行条件

[Opentrons 官方 Gantry Speed 文档](https://docs.opentrons.com/python-api/robot-position/#gantry-speed)将 OT-2 默认速度 400 mm/s 描述为最高已知可靠速度，并要求进一步提速先联系 Support。本次以 **400 mm/s 为测试上限**，没有修改加速度、电流、steps/mm、固件或轴限位。该文档没有规定音乐音域、最小可辨识音符时长或音乐 BPM。

测试设备为一台 OT-2，软件 26.6.0，固件 1.1.0；左侧 p300_multi_gen2，右侧空。使用此前确认的无枪头、无液体测试配置。每次执行前检查当前状态、等待空闲，先上传分析并核对模拟动作，再执行一次。

保留用户要求的 100 mm X 区间 146.5–246.5 mm，计划要求至少 5 mm 内缩；实测命令范围 **156.5–236.5 mm**，两侧实际各留 10 mm。Y 固定 178.75 mm。每轮先 home，此后所有直接移动固定实际读取的 **Z=189.27 mm**，结束时重新读取相同 Z。此处的 Z 不动指 home 完成后的测试运动。

音域测试单程不超过 80 mm，同一速度双向重复，高速通常四次。节奏测试预先生成整段轨迹，每四个音换向，音符之间无主动停顿。每组为 D2–F2–D3–F2 重复四遍，共 16 音。两组之间的定位和静音时间不计入节奏。

## 音域证据

沿用之前校准的模型 `f_model = 4.98375 × speed_mm_s`。下表的 Hz 是目标/模型值；检测结果来自录音，不能用模型值冒充测量值。

| 测试目标 | 指令速度 mm/s | 录音证据 |
|---|---:|---|
| C1，32.703 Hz | 6.562 | 双向均有约 97.7、130.5、521.9 Hz 等倍频成分；基频主要由谐波推断 |
| C2，65.406 Hz | 13.124 | 双向均有约 130.8、326.9、522.9、1045.9 Hz 等成分；低次谐波可重复 |
| C3，130.813 Hz | 26.248 | 双向重复的高次谐波明显；目标基频只在一个方向通过持续性判据 |
| C4，261.626 Hz | 52.496 | 双向均有谐波证据；目标基频只在一个方向通过持续性判据 |
| C5，523.251 Hz | 104.991 | 四次均检测到约 523.1–523.2 Hz，合格窗口中心跨度约 720 ms |
| C6，1046.502 Hz | 209.983 | 四次均检测到约 1045.6–1046.8 Hz，跨度约 290–300 ms |
| E6，1318.510 Hz | 264.562 | 四次均检测到约 1316.6–1317.3 Hz，跨度约 160–180 ms |
| G6，1567.982 Hz | 314.619 | 四次均检测到约 1560.0–1568.2 Hz，跨度约 100–140 ms |
| A6，1760 Hz | 353.148 | 四次均检测到约 1752.4–1761.6 Hz，跨度约 80–110 ms |
| B6，1975.533 Hz | 396.395 | 目标基频未通过持续性判据；仅部分重复出现短暂高次谐波，不计作可靠音符 |
| 模型 1993.5 Hz | 400 | 目标基频未通过持续性判据，不计作可靠音符 |

A6 是本次最高通过判据的标准音名测试点；未测 A♯6，不能断言边界恰好落在 A6。以上跨度是连续合格频谱窗口的**中心时间跨度**，不是额外测得的匀速平台长度。

低端另测 0.125、0.25、0.5、1、2、4 mm/s。前三档没有通过本次检测判据；1–2 mm/s 主要只见很高阶、容易产生歧义的谐波。在 4 mm/s 已能找到与约 19.935 Hz 模型相符的多条倍频成分，但这不足以证明一个清晰可辨的 20 Hz 音符。因此本次没有确定听感音域的低端极限，也不把机械声中所有高频峰当作新增音符。

速度越高，80 mm 行程可留给稳态发声的时间越短。音域和音符时长必须一起考虑；本次约 0.1 秒的高音证据不能用于保证 A6 长音。当前证据也不能单独判断 B6 的不稳定来自加减速、结构共振、收音条件还是其他环节。

## 节奏测量

“名义时长”是距离除以指令速度，不包括控制器执行开销和加减速。实际起音间隔使用机器人端相邻移动命令的 `startedAt` 差值，整段吞吐为 16 除以 BLOCK_BEGIN 注释完成至 BLOCK_END 注释开始的时间（包含极少量块内调度开销）；两者统计口径不同。

| 名义时长 ms | 实际间隔中位数 ms | 整段吞吐 音/秒 | 参考特征匹配 |
|---:|---:|---:|---:|
| 250 | 345 | 2.89 | 16/16 |
| 125，第一轮 | 222 | 4.51 | 16/16 |
| 125，补测 | 214 | 4.54 | 15/16 |
| 100 | 190 | 5.21 | 15/16 |
| 80 | 171 | 5.84 | 12/16 |
| 62.5 | 154 | 6.50 | 10/16 |
| 31.25 | 123 | 7.87 | 10/16 |
| 15.625 | 110 | 8.76 | 5/16 |

125 ms 两轮合计 31/32 匹配，100 ms 为 15/16；这些小样本不能解释为有保证的成功率。实际整段约 4.5–5.2 音/秒对应连续八分音符约 **135–156 BPM**、连续十六分音符约 **68–78 BPM**。若优先保证音符区别，250 ms 测试点表现更好，整段约 2.9 音/秒。

每音约 90–100 ms 的额外时间在这些数据中十分明显。预先编排整段轨迹已经消除了逐音网络提交，但当前 API 仍逐条执行移动，因此不能把 `distance/speed=15.625 ms` 当作实际每秒 64 音。此次未测试固件队列改造、多轴复音或绕过官方 API 的连续运动方式，也没有证明 8.76 音/秒是所有实现方式的硬上限。

## 录音与判据

Linux 耳机麦克风，48 kHz、单声道、16-bit PCM，PipeWire 输入音量 0.20、Headset Mic Boost 0 dB。排除录音启动瞬态。每轮记录主机与机器人的时钟差，通过慢速校准乐句进一步对齐音频。两轮相对于初始时间映射的校正分别为 +65 ms、+70 ms；这不是声传播延迟的测量。

音域检测在对齐后的动作区间内取 Hann FFT 窗口，窗口完整位于该区间。目标频率低于 300 Hz 时窗口 240 ms；其他情况下，速度低于 128 mm/s 用 120 ms，否则用 40 ms。候选谐波阶数为 1–8、16、32、64，目标成分限制在 70–6000 Hz。

合格帧要求插值频率距目标不超过 25 cents、相对附近静音段至少高 10 dB、相对局部频谱中位数至少高 8 dB。连续合格窗口中心跨度至少达到 `max(40 ms, window/2)`。这是**根据目标寻找谐波的验证**，不是不带先验的基频识别；弱基频、倍频听感和八度歧义仍然存在。

节奏辨识用 40 ms 频谱窗，比较 100–3000 Hz 中扣除静音背景后的特征。每轮 1 秒名义时长的乐句提供慢速参考，0.5 秒乐句用于选择时间对齐；对更快组不再调整对齐或模板。对齐校准帧匹配为第一轮 97.5%、补测 100%。在每个更快音符的对齐后命令中点分类，报告是否符合 D2/F2/D3 顺序。这衡量三种音符的**频谱特征可分性**，不是人工听辨测试，也不是全音域绝对音准测试。没有声称已人工试听。
